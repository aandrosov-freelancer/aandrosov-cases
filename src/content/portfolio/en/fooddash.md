## About the Project

**FoodDash** is a high-traffic mobile application for ordering meals and groceries. It provides a live map with 5-meter courier GPS accuracy and automated optimal route selection.

---

## Key Features

- **Live Order Tracking**: Real-time courier position streaming via WebSockets.
- **Smart Search & Recommendations**: Personalized dish suggestions based on dietary preferences.
- **One-Tap Checkout**: Apple Pay, Google Pay, and saved card instant payment.
- **Live Activities**: Dynamic Island and lock screen order updates.

---

### Results

- Average delivery time reduced by **18%** through smart courier routing.
- **42%** D30 user retention rate.
