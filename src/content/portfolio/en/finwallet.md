## About the Project

**FinWallet** is a smart financial companion unifying multi-currency accounts, AI-driven expense categorization, and portfolio investment insights inside a sleek, dark-mode interface.

Designed with bank-grade security and sub-second transaction speeds at its core.

---

## Key Features

- **Bank-grade Security**: End-to-end encryption, Biometric ID protection (Face ID / Touch ID), and hardware key support.
- **AI Expense Analytics**: Automated transaction tagging with visual breakdown charts.
- **Instant Multi-currency Exchange**: Manage fiat currencies and digital assets in a single wallet.
- **Home Screen Widgets**: Quick glance at balances and one-tap payment shortcuts.

---

### Results

- Security architecture passed independent **PCI DSS Compliance** audit.
- Cold app startup time under **0.8 seconds**.
- Over **1,000,000 transactions** processed monthly without downtime.
